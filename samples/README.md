# Sample Extracted Frames

This directory contains sample frames extracted from the fruit fly video recordings for pose estimation model development.

## Sample Files

- `run_231020_seg000_frame41934.jpg` - Sample from October 20, 2023
- `run_231020_seg001_frame1668.jpg` - Sample from October 20, 2023  
- `run_231106_seg000_frame6648.jpg` - Sample from November 6, 2023
- `run_231127_seg000_frame27695.jpg` - Sample from November 27, 2023

## Full Dataset

The complete dataset contains 240 extracted frames across 3 recording dates:
- **Total Frames**: 240 frames
- **Resolution**: 2448x2048 pixels
- **Format**: JPEG
- **Naming Convention**: `{run_date}_seg{segment:03d}_frame{frame_number}.jpg`

## Usage

These sample frames can be used for:
- Model development and testing
- Annotation and labeling
- Quality assessment
- Pose estimation training

The full dataset is available in the `Extracted_Frames_task/` directory (not included in this repository due to size constraints).
